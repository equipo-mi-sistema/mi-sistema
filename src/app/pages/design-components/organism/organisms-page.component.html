El Host Shell actúa como la aplicación contenedora raíz. Se encarga del diseño base (Navbar, Sidebar y Menú reutilizable), la autenticación de usuarios con Firebase y la carga dinámica bajo demanda (lazy-loading) de los microfrontends remotos. A través de la carpeta compartida src/app/shared/components, exponiendo índices de barril limpios para que cualquier página o módulo los consuma sin duplicar código CSS ni dependencias. Permite prescindir completamente de NgModule, reduciendo el tamaño del bundle, agilizando el tree-shaking y permitiendo el uso nativo de Signals e inputs modernos.

Características del Componente:

  • Submenús automáticos: Al hacer clic en una opción con children, despliega o contrae sus hijos.
  • Detección de ruta activa: Si el usuario navega a un submenú, el padre se abre automáticamente.
  • Responsive & Drawer: Se integra tanto en el sidebar de escritorio como en el drawer móvil.
  • Completamente desacoplado: Recibe [items] vía Input y emite (itemClicked) vía Output.
